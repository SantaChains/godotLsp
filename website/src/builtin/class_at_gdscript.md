# @GDScript

> A list of utility functions and annotations accessible from any script written in GDScript.

GDScript 语法级全局：内建函数（`print`/`range`/`preload`/…）与常量（`PI`/`TAU`/…）。
完整成员清单见语法篇；此处骨架保证链接契约完备。
