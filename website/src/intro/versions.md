# 版本与适配说明

## 版本基线

本书以 **Godot 4.x**（4.3+ 行为，4.4 特性会单独标注，如 typed Dictionary）为基线。
GDScript 3.x 的语法不再系统覆盖，只在两处出现 3.x 内容：

- **附录的 3.x → 4.x 迁移表**（旧项目升级用）；
- 正文里关键断代点的一行提示（如 `yield` → `await`、`export` → `@export`）。

## 文档锚点约定

本站所有锚点为显式指定（mdBook 标题属性 `{#id}`），不依赖标题文本推断。
LSP 内核生成链接的规则：

| 目标 | URL |
|---|---|
| 类 | `/builtin/class_<类名小写>.html` |
| 方法 / 常量 / 信号 / 属性 / 枚举成员 | 同上页 + `#<原名>` |
| 枚举 | 同上页 + `#enum-<Enum名>` |
| 关键字 / 操作符 / 注解 | `/syntax/*.html#<标识符>` |

该契约由 `cargo test` 中的 URL 一致性测试保护：内核能生成的每个链接，
都必须命中站内真实标题，缺一即构建失败。

## 内容来源与版权

- **godot-docs**（Godot 官方文档英文语料，CC BY 3.0）：本站类参考与部分语法内容
  在其基础上翻译、重组织并标注修改。
- **godotlsp 逆向成果**（`docs/engine-analyzer.md`）：引擎内部篇的
  uid 算法、.tscn 解析规则、静默失败清单来自对 Godot 源码的核验，为本书独有内容。
- 与引擎内置模型（`gdscript-api`）同源生成的签名表保证类参考与 LSP 补全/hover
  数据一致。

内容与 Godot 上游存在时间差时，以你所用引擎版本的实际行为为准。
