# Introduction

这是 **godotlsp**（GDScript Language Server）配套的 GDScript / Godot 中文参考站。

它有两个身份：

1. **LSP 的文档跳转目标**。在支持 godotlsp 的编辑器里，hover 任意内置类、方法、
   常量、枚举、注解、关键字或操作符，出现的「📖 中文文档」链接都指向本站对应锚点——
   每个条目都有稳定 URL，由 CI 与内核的防漂移测试锁定。
2. **一份独立可读的中文参考**。不装插件也能读：语法 → 范式 → 引擎内部 → 类参考，
   四篇层进。

## 全书结构

| 篇 | 回答的问题 | 适合谁 |
|---|---|---|
| **语法篇** | GDScript 怎么写？ | 已会任意一门语言的人 |
| **范式篇** | Godot 为什么这样设计？节点/场景/信号怎么协作？ | 写得出语法但"不像 Godot 代码"的人 |
| **UI 架构篇** | 界面长到多控件联动后怎么保持可维护？状态和控件怎么分？ | 菜单/HUD 互相牵连、改一处崩三处的人 |
| **引擎内部篇** | 引擎拿到我的文件后做了什么？uid、管线、资产怎么联动？ | 想理解"为什么"，以及遇到静默失败要找原因的人 |
| **类参考** | 每个类/方法/常量的签名与语义 | 写代码时的速查 |

通用编程概念（if、循环、函数定义）一律合并快讲；Godot 特有的
（注解、信号、`$`/`%`、await、autoload、场景生命周期）独占篇幅深挖。
