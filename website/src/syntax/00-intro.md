# 语法篇导读

本篇是 GDScript 语言本身的标准参考：**从词法到协程，16 章覆盖语言的每一个构造**。写法遵循「先结论、再示例、再细节」，所有示例都可在 Godot 4.x 中直接运行。

## 阅读路线

| 你是谁 | 建议路径 |
|---|---|
| 完全新手 | 01 → 02 → 03 → 05 → 11，跑通第一个节点脚本 |
| 从 Python / Lua / TS 过来 | 01（异同表）→ 06（`/` 整数截断等语义陷阱）→ 09（注解）→ 10（信号） |
| Godot 3.x 老手 | [迁移表](../appendix/migration.md) → 12（yield→await）→ 08（static var 等 4.x 新特性） |
| 查语法细节 | 直接用右上角搜索，或从 [注解全表](09-annotations.md)、[运算符全表](06-operators.md) 进入 |

## 与本站其他篇的关系

- **语法篇讲「语言」**：`var`、`func`、`signal` 这些关键字属于语言层，任何 Godot 工程通用。
- **[范式篇](../paradigm/01-pillars.md)讲「模型」**：节点/场景/信号三大支柱如何组织游戏。
- **[类参考](../builtin/index.md)讲「API」**：每个类、每个成员的签名与锚点，与 LSP hover 一一对应。

> 值得注意的是：GDScript 是**依附节点**的脚本语言，不是通用独立语言——语言层的大半特性（信号、注解、`$` 路径）都服务于场景树模型。纯语言视角理解不了 `@onready` 为什么存在，遇到瓶颈时去[范式篇](../paradigm/01-pillars.md)补模型。
