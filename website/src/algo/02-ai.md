# AI 与寻路

**A* 是最常用的寻路。简单敌人用状态机，复杂用行为树。Godot 内置 NavigationAgent。**

## A* 核心

```
F = G + H
G = 从起点走到当前点的实际代价
H = 从当前点到终点的估计代价（启发函数）
```

启发函数必须 **admissible**（不高估实际距离），否则找不到最优路径。

| 启发函数 | 适用 |
|---|---|
| 曼哈顿距离 | 网格四方向 |
| 欧几里得距离 | 任意方向 |
| 对角线距离 | 网格八方向 |

## Grid vs NavMesh

| | Grid | NavMesh |
|---|---|---|
| 表示 | 规则网格 | 多边形可行走区域 |
| 内存 | 大 | 小 |
| 精度 | 低（阶梯路径） | 高（平滑） |
| Godot | AStarGrid2D | NavigationRegion2D/3D |

## Godot 用法

```gdscript
# NavigationAgent2D 挂在敌人身上；目标移动时每物理帧刷新 target_position
@onready var agent := $NavigationAgent2D

func _physics_process(delta: float) -> void:
    agent.target_position = player.global_position
    if agent.is_navigation_finished():
        return
    var next := agent.get_next_path_position()
    var dir := (next - global_position).normalized()
    velocity = dir * speed
    move_and_slide()
```

> `target_position` 不是设一次就够：目标移动后要持续更新，代理才会重新算路；到达后 `is_navigation_finished()` 为 true，停止推进避免原地抖动。

## 状态机（简单敌人）

```gdscript
extends CharacterBody2D

enum State { IDLE, CHASE, ATTACK, DEAD }
var state: State = State.IDLE

func _physics_process(delta):
    match state:
        State.IDLE:
            if player_nearby():
                state = State.CHASE
        State.CHASE:
            velocity = direction_to(player) * speed
            if in_attack_range():
                state = State.ATTACK
            elif lost_player():
                state = State.IDLE
        State.ATTACK:
            do_attack()
            state = State.CHASE
        State.DEAD:
            queue_free()
    move_and_slide()
```

## Steering Behaviors

| 行为 | 公式 |
|---|---|
| Seek | 朝目标方向最大速度移动 |
| Flee | 远离目标 |
| Arrive | 接近目标时减速 |
| Wander | 随机方向平滑游走 |

## 行为树

复杂 AI 用行为树：选择器（OR）、序列（AND）、并行节点。Godot 无内置行为树，用插件或自己搭。状态机适合 3-5 个状态，超过就上行为树。
