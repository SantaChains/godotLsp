# Godot 节点速查表

来源:类名与职责按 Godot 4.5 官方类参考(docs.godotengine.org/zh_CN)校准;中文译名采用官方中文文档惯例,无官方译名者按字面直译。

## 版本基线(Godot 4.x 迁移要点)

- TileMap 已弃用,改用 TileMapLayer(多实例叠加代替单节点多图层)。
- AnimationPlayer 与 AnimationTree 统一继承 AnimationMixer。
- VisibilityNotifier/VisibilityEnabler 更名 VisibleOnScreenNotifier/VisibleOnScreenEnabler。
- ParallaxBackground + ParallaxLayer 由 Parallax2D 取代(4.3+,旧节点保留)。
- 4.4 起可选用内置 Jolt Physics(3D);默认仍为 Godot Physics。
- GraphEdit 系列在 4.x 重构,新增 GraphElement/GraphFrame。

## 转写稿事实修正

1. 2D 关节官方仅三种:DampedSpringJoint2D、GrooveJoint2D、PinJoint2D;不存在 2D 滑动关节(滑动关节仅 3D)。
2. Godot 4 无 PhysicalBone2D;2D 骨骼仅 Skeleton2D + Bone2D。PhysicalBone3D 属于 3D。
3. 无独立 RadioButton 节点;单选用 CheckBox/CheckButton 配 ButtonGroup(ButtonGroup 是资源,非节点)。
4. Theme 是资源(Resource),挂于 Control 或项目设置,不是节点。

覆盖约 160 个节点,含全部常用节点;未列入者为资源类、服务单例或实验性节点。
